# 01 研究协议

本文件是中文协议摘要；机器可读 single source of truth 是
`specs/protocol_v4.yaml`。旧 K-date/few-shot 文本只保留为 secondary ablation。

## 任务定义

对于每个日期、区域和 patch：

```text
ΔSM_surface  = sm_surface_analysis  - sm_surface_forecast
ΔSM_rootzone = sm_rootzone_analysis - sm_rootzone_forecast
```

模型输出 increment，并通过 `forecast + pred_increment` 重建 estimated analysis。
这不是 generic soil moisture prediction。

## 时间协议

```text
Source fit/train:
  2015-01-01 到 2021-12-31

Source val:
  2022-01-01 到 2022-12-31

Target train/adaptation:
  2015-01-01 到 2021-12-31

Target val:
  2022-01-01 到 2022-12-31

Target held-out evaluation:
  2023-01-01 到 2025-12-31
```

如果实际数据覆盖不同，audit 脚本必须明确报告，并且 split builder 不能静默修改协议。

## Target full-training-set adaptation

主实验设置：

```text
adaptation_setting = target_full_train
```

目标域泛化不再是 few-shot adaptation。HyperDA / prompt / adapter / LoRA /
generated-parameter 方法在 source/HyperDA 训练完成后，可以使用完整 2015-2021
target_train 样本构造 target-specific operator。2023-2025 target_eval labels
只允许用于最终离线评估。

主协议不再单独保留 support set；`target_support` 只是旧代码 alias。

## Source 覆盖范围

主协议保持：

```text
source_fit = 2015-2021
source_val = 2022
```

2022 保留为 source-domain checkpoint / early stopping / hyperparameter selection
gate。纳入 2022 的 source refit 只能作为 expanded-source secondary ablation。

## Legacy K-date ablation

旧 K-date 设定只作为 secondary few-shot ablation：

```text
legacy_few_shot_K = 0, 4, 12
```

K 是目标区域 2015-2021 target_train 中的 DA analysis dates/cycles 数量，不是 pixels、
patches 或 mini-batches 数量。所有 legacy 方法在同一个
`country, region, K, seed` 下必须使用相同 support dates。

## 主实验

### Experiment 1：US-only development OOD

Leave-one-US-region-out：

```text
source = 其他 5 个 US regions, 2015-2021
source_val = 其他 5 个 US regions, 2022
target_train = held-out US region, 2015-2021
target_val = held-out US region, 2022
target_eval = held-out US region, 2023-2025
```

### Experiment 2：Leave-one-continent-out

```text
Train US+CN -> Target AU
Train US+AU -> Target CN
Train CN+AU -> Target US
```

### Experiment 3：Same-regime cross-continent transfer

对每个 regime triad：train two countries, test held-out country。

### Experiment 4：Adaptation mechanism ablation

比较 source-only、prompt-conditioned shared、adapter、LoRA、HyperDA generated
operator、HyperDA refine。full fine-tuning/head tuning/bias-only/AdaBN 可作为附录。

### Experiment 5：High-update scientific event analysis

预测完成后，再从 target_eval years 中选择事件。事件选择不能用于模型选择。

## 信息泄漏规则

禁止：

```text
target_eval/query labels 用于 training
target_eval/query labels 用于 prompt construction
target_eval/query labels 用于 normalization
target_eval/query labels 用于 target adaptation sample selection
target_eval/query labels 用于 early stopping
target_eval/query labels 用于 model selection
target_eval/query labels 用于 region selection
analysis increments 用于定义 region regimes
model errors 用于重新定义 regions
```
