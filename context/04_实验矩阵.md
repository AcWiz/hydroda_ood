# 04 实验矩阵

本文件是旧中文实验矩阵的兼容入口。当前主协议以
`CLAUDE.md`、`docs/COAUTHOR_CONTEXT.md`、`context/01_RESEARCH_CONTRACT.md`
和 `specs/protocol_v4.yaml` 为准。

## 当前主线

US-only development 阶段使用 leave-one-region-out 调试完整 pipeline：

```text
source regions: 其余 US regions
source fit/train: 2015-2021
source val: 2022
target_context: 2015-2021 input-side only
target_support: K labeled cycles, K in {0,4,12}
target_val: unused in main protocol
target_eval: 2023-2025
adaptation_setting: zero_shot_context | few_shot_k4 | few_shot_k12
```

最终论文主线为 leave-one-continent-out：

```text
US + CN -> AU
US + AU -> CN
CN + AU -> US
```

## 主表方法

```text
Forecast-only
Source-only backbone
Prompt-conditioned shared backbone
HyperDA K=0 target-context prompt
HyperDA K=4 lightweight target adaptation
HyperDA K=12 lightweight target adaptation
```

## Legacy / Archive

旧 `target_full_train`、`target_query`、HyRAO-Meta 和 FISA/HISA 主线表述均属于
历史方案。它们只能作为 secondary ablation、legacy reproduction 或内部诊断，
不应进入当前论文主表。

旧 baseline 名称：

```text
target_support_mean_increment
target_monthly_support_increment
ridge_calibration
source_mean_increment
```

当前只能作为 internal sanity check 或 legacy result label。

## 事件分析

事件分析只能在模型、超参数和 checkpoint 冻结之后进行，并且只能把
`target_eval=2023-2025` labels 用于最终解释和可视化，不能用于模型选择。
