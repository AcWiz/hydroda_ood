# 04 实验矩阵

本文件是旧中文实验矩阵的兼容入口。当前主协议以
`CLAUDE.md`、`docs/COAUTHOR_CONTEXT.md`、`context/01_RESEARCH_CONTRACT.md`
和 `specs/protocol_v4.yaml` 为准。

## 当前主线

US-only development 阶段使用 leave-one-region-out 调试完整 pipeline：

```text
source regions: 其余 US regions
source fit/train: 2015-2021
source val: 2021
target_train/adaptation: 2015-2021
target_eval: 2023-2025
adaptation_setting: target_full_train
```

最终论文主线为 leave-one-continent-out：

```text
US + CN -> AU
US + AU -> CN
CN + AU -> US
```

## 主表方法

```text
Forecast-only
Source-only backbone
Prompt-conditioned shared backbone
Adapter tuning on full target_train
LoRA tuning on full target_train
HyperDA generated operator from full target_train
HyperDA generated operator + full target_train calibration
HyperDA-Refine with full target_train
```

## Legacy / Archive

旧 `K=0/4/12`、`target_context`、`target_support`、`target_query`、HyRAO-Meta
和 FISA/HISA 主线表述均属于历史方案。它们只能作为 secondary ablation、
legacy reproduction 或内部诊断，不应进入当前论文主表。

旧 baseline 名称：

```text
target_support_mean_increment
target_monthly_support_increment
ridge_calibration
source_mean_increment
```

当前只能作为 internal sanity check 或 legacy result label。

## 事件分析

事件分析只能在模型、超参数和 checkpoint 冻结之后进行，并且只能把
`target_eval=2023-2025` labels 用于最终解释和可视化，不能用于模型选择。
