# HyperDA v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first HyperDA implementation: a bottleneck-only basis-generated adapter conditioned on the existing safe region prompt.

**Architecture:** Reuse the existing Phase 4 prompt-conditioned trainer and protocol. Add a new `hyperda_basis_adapter` model type that swaps the FiLM UNet for a bottleneck adapter UNet whose adapter bases are mixed by prompt-derived coefficients.

**Tech Stack:** Python, PyTorch, pytest, existing HydroDA dataset/trainer utilities.
