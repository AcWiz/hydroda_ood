# HyperDA-OOD / HyperDA V4 完整研究计划

本文件为当前项目冻结版研究计划。旧版 HyRAO / sparse adaptation / simple-baseline 主表计划全部降级为历史方案或 internal sanity check。

## 0. 最终论文定位

这篇论文不写成“更好的土壤湿度预测模型”，而写成：

```text
HydroDA-OOD:
A leakage-controlled cross-continental benchmark for neural land data assimilation increment emulation.

HyperDA-TRUST:
A source-trained prompt-conditioned operator generator with Source-Manifold Trust Routing for leakage-controlled zero-shot target-specific neural DA increment operators.
```

一句话中文版本：我们构建一个严格防泄漏的跨大陆 neural land DA increment emulation 协议，并提出 HyperDA-TRUST，用 source-trained prompt-conditioned hypernetwork 从 input-side target context 生成 target-specific DA correction operator，再用 source-only trust bank 将 target operator coefficients 约束到 source-supported operator manifold。

## 1. 核心科学问题

```text
Can source-trained HyperDA priors and source-manifold trust routing generate target-specific neural data assimilation increment operators under zero-shot cross-continental hydroclimatic shift without target labels?
```

我们真正回答：为什么不是 forecast-only，为什么不是 source-only，为什么不是 prompt-conditioned shared backbone，为什么需要 zero-shot target-specific parameter generation，以及 source-only trust routing 是否能在不读 target labels 的情况下稳定 operator generation。

## 2. 核心贡献

Contribution 1：HydroDA-OOD benchmark / protocol。严格区分 source fit、source val、target context / support 和 target_eval，并工程化防止 target_eval leakage。任务是 DA analysis-increment operator emulation，不是 soil moisture prediction。

Contribution 2：HyperDA Operator Generator。不是把 prompt 拼到输入特征里，而是用 source-trained frozen backbone、target-context prompt 和 stable rank-gated bounded-DoRA lightweight operator generation，在 K=0 下从 input-side target context 生成 target-specific DA increment operator。

Contribution 3：Source-Manifold Trust Routing / HyperDA-TRUST。只用 source_fit/source_val 构建 source trust bank，通过 nearest-source operator coefficient consensus 和 target coefficient routing 约束 target-prompt operator 不偏离 source-supported operator manifold，不使用 target labels。

Contribution 4：可引用强 baseline 与可证伪分析。主表聚焦 forecast-only、source-only、prompt-conditioned shared、HyperDA K=0 Operator Generator、HyperDA-TRUST K=0。SAFE K=4/K=12 当前只作为 diagnostic / frozen future extension；若展示必须标注 `rejected_to_k0_anchor`，不能写成 accepted few-shot adaptation。Adapter/LoRA K-shot 与 full-target legacy 结果只作为 secondary ablation 或 internal reproduction。

## 3. 任务定义

任务是 neural land DA analysis-increment emulation：

```text
ΔSM_surface  = SM_surface_analysis  - SM_surface_forecast
ΔSM_rootzone = SM_rootzone_analysis - SM_rootzone_forecast
```

模型输出 `pred_increment_surface/rootzone`，再加回 forecast 得到 `pred_analysis_surface/rootzone`。

必须反复强调：

```text
We do not predict soil moisture from scratch. We emulate the correction operator induced by a physical / operational DA system.
```

## 4. 数据与区域

最终主实验使用 US/CN/AU，每个大陆 6 类 hydroclimatic regimes：R1 dryland、R2 semi-arid transition、R3 irrigated agriculture、R4 rainfed agriculture、R5 humid high vegetation、R6 mountain/cold terrain。

区域定义必须在训练前冻结，不能根据模型表现、analysis increments 或 target query labels 调整。

## 5. 主实验协议

Leave-one-continent-out：

```text
US + CN -> AU
US + AU -> CN
CN + AU -> US
```

Protocol V4.4 zero/few-shot 时间协议：

```text
Source fit/train:           2015-2021
Source validation:          2022
Target context:             2015-2021 input-side only
Target support:             K labeled cycles, K in {0,4,12}
Target validation:          unused in main protocol
Target eval/test:           2023-2025
```

`source_val=2022` 只能来自 source continents，用于 checkpoint selection、early stopping 和 hyperparameter / architecture selection。`target_context=2015-2021` 只使用 input-side 信息构造 target-context monthly prompt prototypes。`target_support` 是从 2015-2021 通过 calendar + availability/base_valid coverage 选择的 K 个 labeled DA cycles。`target_val=2022` 主协议不使用。`target_eval=2023-2025` 只用于最终 evaluation。

`month` 只表示部署时已知的 month-of-year seasonal phase，用于选择对应 monthly prototype；它不是绝对日期标签，也不是 target_eval 模型选择信号。

主协议：

```text
K ∈ {0,4,12}
adaptation_setting ∈ {zero_shot_context, few_shot_k4, few_shot_k12}
```

`target_full_train` 仅作为 legacy/internal reproduction 路径，必须显式 opt-in。K 是 target_support 中的 DA cycles，不是 patches。

主协议 source 覆盖范围保持 `source_fit=2015-2021`、`source_val=2022`；更长 source fit 只能作为 expanded-source ablation。
## 6. Leakage Guard

禁止 target_eval/query labels 用于 prompt construction、normalization、target adaptation sample selection、training、early stopping、model selection、threshold calibration、prompt feature tuning。主协议还禁止 target_val/target_eval 参与 target-side selection、early stopping 或 residual-gain calibration。

所有模块必须共享 `ProtocolConfig` 与 `LeakageGuard`：PromptBuilder、Normalizer、SupportSampler、Dataset、Evaluator、ExperimentRunner。

## 7. 方法：HyperDA-V4

```text
ζ_R = H_ψ(P_R)
ΔSM_hat_R = f_{θ0, ζ_R}(x_R)
```

组件：shared DA increment backbone、source operator episode bank、prompt encoder、basis-factorized hypernetwork parameter generator。

第一版不生成 full backbone weights，只生成 adapter、output-head residual、optional FiLM。

Basis factorization：

```text
ζ_R,l = ζ_0,l + Σ_m α_R,l,m B_l,m
```

## 8. 主版本

HyperDA Operator Generator / HyperDA-ZeroShot-Context：K=0，只用 2015-2021 target_context input-side
monthly prompt prototypes 直接生成 target lightweight operator，不使用 target labels。

HyperDA-TRUST / Source-Manifold Trust Routing：M3_1 在 HyperDA K=0 operator
generation 上增加 source-only trust bank、nearest-source coefficient
consensus 和 target coefficient routing。其功能定位是 label-free safety /
regularization：在 target prompt 不被 source operator manifold 支持时，将
lightweight operator coefficients 路由到 nearest source-neighborhood consensus，
并记录 surface/rootzone trust gates。它不使用 target labels、target_val 或
target_eval statistics 做 selection。

SAFE K=4/K12：当前作为 diagnostic / frozen future extension 保留。从冻结的
source-trained `Hψ` 与 target-context monthly prompt prototypes 初始化，target
阶段冻结 source backbone、prompt encoder、`Hψ` 和 adapter basis bank，只允许在
K 个 labeled support cycles 上训练 lightweight target-specific variables。
当前 US-R1 K=4/K=12 结果均为 `rejected_to_k0_anchor`，RMSE 与 K=0 完全一致，
说明现阶段没有 accepted few-shot adaptation 证据，不能作为主贡献宣称。

K=4/K=12 paper-facing runs 必须读取 source-side episode calibration 导出的
`safe_policy.json`，记录 `policy_source=source_side_episode_calibration`、
policy hash、support manifest hash 和 `adapt_mix_rho`。缺失该 policy 的 K-shot
运行只能作为 diagnostic 或 K0-anchor fallback；所有 K-shot 表格必须标注
`rejected_to_k0_anchor` 或 accepted/future-extension status。

`target_full_train` / HyperDA-Adapt-FullTargetTrain / HyperDA-Refine-FullTargetTrain
仅保留为 legacy/internal reproduction，不进入主表。

## 9. Baseline 体系

主表：Forecast-only、Source-only backbone、Prompt-conditioned shared backbone、
HyperDA Operator Generator K=0、HyperDA-TRUST K=0。SAFE K=4/K=12 只作为
diagnostic / future extension 表格，不能写成当前 accepted few-shot improvement。
Adapter/LoRA K-shot 与 full-target legacy 结果放附表或后续消融。

删除主表 baseline：source mean、target support mean、ridge、nearest-source、prompt-weighted、kNN interpolation、linear prompt-to-parameter。

## 11. 主指标

主文报告 Surface Skill、Rootzone Skill、Increment RMSE、Increment correlation、High-update Skill。

Forecast-relative skill：

```text
Skill = 1 - RMSE(SM_hat_analysis, SM_analysis) / RMSE(SM_forecast, SM_analysis)
```

## 12. 审稿风险

关键防御：任务不是 soil moisture prediction；target_eval label zero leakage；主协议 zero/few-shot 标签预算明确；K 是 DA cycles 不是 patches；Prompt-conditioned shared baseline 必须强；Adapter/LoRA 必须公平；source episodes 不是 independent domains，而是 structured local operator estimation problems。
