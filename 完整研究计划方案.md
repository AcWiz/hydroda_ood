# HyperDA-OOD / HyperDA V4 完整研究计划

本文件为当前项目冻结版研究计划。旧版 HyRAO / sparse adaptation / simple-baseline 主表计划全部降级为历史方案或 internal sanity check。

## 0. 最终论文定位

这篇论文不写成“更好的土壤湿度预测模型”，而写成：

```text
HydroDA-OOD:
A leakage-controlled cross-continental benchmark for neural land data assimilation increment emulation.

HyperDA:
A hydroclimatic spatio-temporal prompt-conditioned hypernetwork for generating target-specific lightweight neural DA increment operators.
```

一句话中文版本：我们构建一个严格防泄漏的跨大陆 neural land DA increment emulation 协议，并提出 HyperDA，从 source operator episode bank 中学习 hydroclimatic spatio-temporal prompt 到轻量 DA operator 参数的映射，为未见目标区域生成 target-specific DA correction operator。

## 1. 核心科学问题

```text
Can hydroclimatic spatio-temporal prompts and full target-training-period adaptation generate target-specific neural data assimilation increment operators that outperform shared conditional models under cross-continental hydroclimatic shift?
```

我们真正回答：为什么不是 forecast-only，为什么不是 source-only，为什么不是 prompt-conditioned shared backbone，为什么不是 adapter / LoRA tuning，为什么需要 target-specific parameter generation。

## 2. 核心贡献

Contribution 1：HydroDA-OOD benchmark / protocol。严格区分 source fit、source val、target context/calibration 和 target query，并工程化防止 query-label leakage。

Contribution 2：HyperDA parameter-space transfer。不是把 prompt 拼到输入特征里，而是根据目标区域 prompt 生成 target-specific lightweight operator parameters。

Contribution 3：DA-specific deterministic basis-factorized generation。借鉴 parameter-space transfer 思想，但不照搬 diffusion 或 full-weight generation；科学 DA 场景优先稳定、可审计、轻量。

Contribution 4：可引用强 baseline 与可证伪分析。主表只比较 forecast-only、source-only、prompt-conditioned shared、adapter tuning、LoRA tuning、HyperDA full-target-train generated operator、HyperDA full-target-train refine。旧 K-shot 结果只作为 secondary ablation。

## 3. 任务定义

任务是 neural land DA analysis-increment emulation：

```text
ΔSM_surface  = SM_surface_analysis  - SM_surface_forecast
ΔSM_rootzone = SM_rootzone_analysis - SM_rootzone_forecast
```

模型输出 `pred_increment_surface/rootzone`，再加回 forecast 得到 `pred_analysis_surface/rootzone`。

必须反复强调：

```text
We do not predict soil moisture from scratch. We emulate the correction operator induced by a physical / operational DA system.
```

## 4. 数据与区域

最终主实验使用 US/CN/AU，每个大陆 6 类 hydroclimatic regimes：R1 dryland、R2 semi-arid transition、R3 irrigated agriculture、R4 rainfed agriculture、R5 humid high vegetation、R6 mountain/cold terrain。

区域定义必须在训练前冻结，不能根据模型表现、analysis increments 或 target query labels 调整。

## 5. 主实验协议

Leave-one-continent-out：

```text
US + CN -> AU
US + AU -> CN
CN + AU -> US
```

Protocol V4-final 时间协议：

```text
Source fit/train:           2015-2021
Source validation:          2022
Target train / adaptation:  2015-2021
Target validation:          2022
Target eval/test:           2023-2025
```

`source_val=2022` 只能来自 source continents，用于 checkpoint selection、early stopping 和 hyperparameter / architecture selection。`target_train=2015-2021` 是 held-out target continent 的完整训练/适配期，可用于 target-specific operator / prompt / adapter / generated parameters。`target_val=2022` 只用于预注册 adaptation validation。`target_eval=2023-2025` 只用于最终 evaluation。

主协议：

```text
adaptation_setting = target_full_train
```

旧 `K ∈ {0, 4, 12}` few-cycle calibration 只作为 secondary ablation。K 是 target_train 2015-2021 中的 DA cycles，不是 patches。

主协议 source 覆盖范围保持 `source_fit=2015-2021`、`source_val=2022`；更长 source fit 只能作为 expanded-source ablation。
## 6. Leakage Guard

禁止 target_eval/query labels 用于 prompt construction、normalization、target adaptation sample selection、training、early stopping、model selection、threshold calibration、prompt feature tuning。

所有模块必须共享 `ProtocolConfig` 与 `LeakageGuard`：PromptBuilder、Normalizer、SupportSampler、Dataset、Evaluator、ExperimentRunner。

## 7. 方法：HyperDA-V4

```text
ζ_R = H_ψ(P_R)
ΔSM_hat_R = f_{θ0, ζ_R}(x_R)
```

组件：shared DA increment backbone、source operator episode bank、prompt encoder、basis-factorized hypernetwork parameter generator。

第一版不生成 full backbone weights，只生成 adapter、output-head residual、optional FiLM。

Basis factorization：

```text
ζ_R,l = ζ_0,l + Σ_m α_R,l,m B_l,m
```

## 8. 主版本

HyperDA-FullTargetTrain：使用 2015-2021 target_train 的 input-side prompt 与 labeled adaptation summaries 生成 ζ_R。

HyperDA-Refine-FullTargetTrain：从 HyperDA 生成的 ζ_R 初始化，冻结 θ0 和 Hψ，只在 2015-2021 target_train 上用预注册步数更新 ζ_R。

HyperDA-Zero / HyperDA-Calib / K=4/12 Refine：保留为旧 few-shot ablation，不进入主表。

## 9. Baseline 体系

target_full_train：Forecast-only、Source-only backbone、Prompt-conditioned shared backbone、Adapter tuning、LoRA tuning、HyperDA generated operator、HyperDA refine。Prompt-conditioned shared backbone 是 shared conditional baseline，不是使用 target_train labels 的 target-adapted method。

删除主表 baseline：source mean、target support mean、ridge、nearest-source、prompt-weighted、kNN interpolation、linear prompt-to-parameter。

## 10. 工程路线

Phase 0：DA.nc audit。

Phase 1：Region cropping，nc 与 pt 分文件夹，每个 region 单独保存。

Phase 2：HydroDADataset + ProtocolConfig + LeakageGuard。

Phase 3：Forecast-only + metrics/evaluation sanity。

Phase 4：Source-only ResUNet/ConvNeXt-UNet + prompt-conditioned shared backbone。

Phase 5：Source operator episode bank。

Phase 6：HyperDA full-target-train generation / calibration。

Phase 7：adapter、LoRA、HyperDA-Refine full-target-train comparison；K=0/4/12 只作为 legacy few-shot ablation。

Phase 8：US-only development report。

Phase 9：CN/AU 到位后扩展到 leave-one-continent-out。

## 11. 主指标

主文报告 Surface Skill、Rootzone Skill、Increment RMSE、Increment correlation、High-update Skill。

Forecast-relative skill：

```text
Skill = 1 - RMSE(SM_hat_analysis, SM_analysis) / RMSE(SM_forecast, SM_analysis)
```

## 12. 审稿风险

关键防御：任务不是 soil moisture prediction；target_eval label zero leakage；主协议允许完整 target_train，但严格 held-out target_eval；旧 K 是 cycles 且仅为 ablation；Prompt-conditioned shared baseline 必须强；Adapter/LoRA 必须公平；source episodes 不是 independent domains，而是 structured local operator estimation problems。
